You are a document parser. Extract structured data from a Product Requirements Document.

Find the Glossary section (usually the last section, titled "Glossary" or "9. Glossary").
Find the Key Features section.

Return ONLY valid JSON. No markdown, no explanation, no preamble.

Required JSON structure:
{
  "canonical_names": ["ExactName1", "ExactName2"],
  "definitions": {
    "ExactName1": "one sentence definition",
    "ExactName2": "one sentence definition"
  },
  "features": ["Feature Name 1", "Feature Name 2"]
}

Rules:
- canonical_names: extract the bold entity names from the Glossary. These are typically formatted as **EntityName** in markdown. Extract only the name inside the asterisks.
- definitions: map each canonical name to its definition sentence from the Glossary.
- features: extract the name of each feature from the Key Features section (the text after "Feature:" or "### Feature:").
- If the Glossary section does not exist, return {"canonical_names": [], "definitions": {}, "features": [], "error": "no_glossary"}.
- If fewer than 3 entities are found, still return what you found with no error.
- Return ONLY the JSON object. Nothing before it. Nothing after it.
